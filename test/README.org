* Running

#+begin_src sh
gmake test                       # everything below, all three engines
gmake test-one T=test/cs-do.fs   # one test, all engines
gmake test ENGINES=gforth-fast   # one engine
gmake goldens                    # regenerate test/expected/, then review the diff
gmake stress CORPUS="path/to/programs/*.fs"
gmake test-lldb                  # lldb/check.sh; SKIPs where debugserver cannot attach
gmake verify                     # the CONTRIBUTING.org baseline
gmake release-check              # verify, release hygiene, dist/ + SHA256SUMS
#+end_src

Needs stock gforth 0.7.3 (=gforth=, =gforth-fast=, =gforth-itc=), GNU make,
bash, perl, python3 (=timeout= or =gtimeout= if present, else perl's
=alarm= gives the 10 s limit). With =uv= the records are also checked by
the =jsonschema= package; without it only by the built-in validator.

=gmake test= is three steps, each of which fails the build:

1. =test-contract=: =test/validate.py= accepts every line of
   =test/contract/good.jsonl= and rejects every line of =bad.jsonl= (NaN,
   Infinity, =3.E0=, raw tab, invalid UTF-8, duplicate key, wrong =v=,
   missing or extra keys, a malformed =contract=, ...).  Both validators
   run and must agree.  Then the consumer rule: =test/consumer.py= must
   accept =test/contract/streams/ok-*.jsonl= and refuse every =bad-*=
   (no hello, no contract, other MINOR, other MAJOR, newest hello
   differs), and =contract-version= in =inspect.fs= must equal the
   schema's =x-contract=.
2. =test-selftest=: =test/selftest.sh= checks the runner goes red on a
   failed assertion, a bad log line, a non-zero exit, a redefinition
   warning, and a tampered golden.
3. =test-goldens=: =test/run.sh= runs each =test/*.fs= in each engine with
   =HOME=, =XDG_STATE_HOME= and =TEST_OUT= in a fresh temp dir (never the
   real =~/.local/state=), stdin from the test's =\ test: stdin= keys, a
   10 s timeout.  It masks addresses, xts, timestamps and the temp path
   (=test/mask.pl=), and compares stdout, stderr, every =*.jsonl= written,
   every file under =$TEST_OUT= and the exit status with
   =test/expected/NAME.out= (or =NAME@ENGINE.out= where an engine really
   differs).  Every =stacks.jsonl= line is validated against the schema.
   A test fails on any =ASSERT FAIL=, schema error, exit status other
   than its =\ test: exit= (default 0), or =redefined= warning; =-u= will
   not bless any of those.

Header directives: =skip=, =stdin=, =noinspect=, =load=, =env=, =unset=,
=exit= (see the top of =test/run.sh=).  =test/lib/assert.fs= gives
=assert ( f c-addr u -- )=, =assert= ( actual expected c-addr u -- )= and
=out-path ( c-addr u -- c-addr' u' )=.

* Known limits

- =gforth-fast= fuses some sequences into static superinstructions (=2 +=
  is one instruction with an inline =2=).  =see= cannot decode them, so
  =dbg= steps over the whole run in one go (=dbg-nest-n@gforth-fast.out=
  shows it).  Since 0.1.0 this only skips display; it no longer corrupts
  the word.
- After =IF x THEN= with a one-cell =x=, the fall-through path is shown
  one step later (the two breakpoint sites are adjacent and only the later
  one can be set).
- =dbg= of a recursive word can stop in a deeper invocation (stock
  behaviour).
- =~~~= in a =:noname= reports its word as =???= (stdout and ="where"=).
- lldb cannot attach inside a sandbox that denies =task_for_pid=;
  =gmake test-lldb= then prints SKIP.  =lldb/log/= is the last transcript
  from outside one, with machine paths masked.
- =gmake verify= runs =gmake -C pbt calibrate=, which is owned by =pbt/=.
  It passes =INSPECT_REF=HEAD=, so the property tests load this
  checkout's committed =env/inspect.fs=, not the =harden= branch.
- Two producers on one log are safe when they take turns
  (=log-two-producers=).  Each record is built in memory and written as
  one line, but two producers writing at the same instant can still
  collide: the seek and the write are separate calls, and 0.7.3's
  =open-file= has no append mode.  That case is best-effort and is
  measured by experiment 005, not gated here.

** 2026-11-21 (#17)

=log-two-producers=: producer A logs, a second gforth of the same engine
(=test/lib/log-producer-b.fs=, started by =system= so the order is fixed)
appends a hello and a snapshot, then A logs again.  Without the
seek-to-end in =(log-append)= A's second record lands on B's hello and
line 4 does not parse, in all three engines; with it all five records
survive.  Records are now built in memory (=type= and =emit= redirected)
and written whole; every golden is byte-identical to before.
The runner now exports =TEST_ENGINE= for tests like this one.

Two numbers: the record version =v= (and the schema's =x-version=) is

* Files

=<dir>= is the first of these that applies (since 0.3.0):

1. =$GFORTH_INSPECT_LOG_DIR=, when it is set and non-empty.
2. =<base>=, when the current directory cannot be read (=get-dir= fails)
   or is longer than 4288 bytes, or the derived directory below would be
   longer than 4339 bytes (inspect.fs's buffers hold 4352, and
   =/stacks.jsonl= takes 13), where =<base>= is
   =${XDG_STATE_HOME:-$HOME/.local/state}/gforth-inspect= (the shared
   default of 0.2.0 and before).
3. The =GFORTH_INSPECT_LOG_DIR= line of =<root>/.env=, when its value is
   non-empty.  =<root>= is the nearest ancestor of the current directory,
   itself included, that holds a =.git= (a directory, or the file of a
   linked worktree), or the current directory when none does.  The
   current directory is the process's own (getcwd, gforth's =get-dir=),
   never =$PWD=: a gforth started in one worktree with =$PWD= inherited
   from another (=subprocess.run(cwd=...)=, an editor's job runner) logs
   to its own worktree, and an unset =$PWD= changes nothing.
   - The line is =[export] GFORTH_INSPECT_LOG_DIR = value=: leading blanks,
     an optional =export= and blanks around === are allowed; a trailing CR
     is dropped; the last such line wins.
   - A value that starts with ='= or ="= is taken inside that pair of
     quotes.  Otherwise it ends before the first =#= that follows a blank
     (a comment) and is trimmed.
   - =~= is =$HOME=, =~/x= is =$HOME/x=, an absolute value is used as it is,
     and any other value is relative to =<root>= (the directory holding the
     =.env=), whichever subdirectory gforth was started in.
   - *Trust boundary.*  A =.env= is committed and comes with a clone, so
     it may not send the log just anywhere: a value with a =..= segment,
     or an absolute value outside =$HOME= (or any absolute value without
     =$HOME=), is refused with one line on stderr,
     =gforth-inspect: ignoring .env GFORTH_INSPECT_LOG_DIR outside $HOME=,
     and the derived default (4.) is used.  So is a value whose path is
     longer than 4339 bytes (=...: too long=).  The environment variable
     is not restricted: it is the user's own.
   This is how a project opts out, for example to make all its worktrees
   share one log: =GFORTH_INSPECT_LOG_DIR=~/.local/state/gforth-inspect/shared=
   in each worktree's =.env=.
4. =<base>/<owner>/<repo>/<worktree>=, read from the files of the git
   metadata (git itself is never run):
   - the git dir is =<root>/.git= when that is a directory; when it is a
     file, the path on its =gitdir: <path>= line (relative to =<root>=).
     The common git dir is the git dir's =commondir= file (relative to the
     git dir), else the git dir itself;
   - =<repo>= is the last segment of the path of the first =url= in the
     =[remote "origin"]= section of the common dir's =config=, =.git=
     stripped; =<owner>= is every segment before it (empty ones dropped),
     joined with =/= and encoded as one component, so GitLab subgroups
     =group-a/sub= and =group-b/sub= stay apart.  Accepted:
     =git@host:owner/repo=, =ssh://[user@]host[:port]/owner/repo=,
     =https://host/owner/repo=, with any number of segments; a url with
     one segment gives owner =_=.  The config is read line by line: a
     section header must be exactly =[remote "origin"]= (=remote= in any
     case), the key =url= in any case, the value trimmed, one pair of ="=
     stripped, no inline comments.  With no origin url, =<owner>= is
     =_local= and =<repo>= is the hashed name of the main worktree: the
     slug of the last-but-one component of the common dir, hashed over the
     common dir's path (=.= and =..= resolved lexically), so two
     repositories with the same name never share one;
   - =<worktree>= is the branch of =HEAD=, =ref: refs/heads/<branch>= (it
     may contain =/=).  Two cases are per worktree directory instead,
     named after =<root>='s last component and hashed over =<root>='s full
     physical path, so two worktrees with the same name never share one:
     a detached =HEAD= gives =_detached-<name>~<hash>=, and a reftable
     repository (=[extensions] refStorage = reftable= in the common config,
     or the stub =HEAD= =ref: refs/heads/.invalid=, which reftable writes
     instead of the branch) gives =_wt-<name>~<hash>=;
   - outside any repository the three are =_nogit=, the hashed name of
     the current directory (its last component's slug, hashed over its
     full physical path), and =_=.

   Each name (owner, repo, branch, directory name) becomes exactly one
   path component: itself when it matches =^[a-z0-9][a-z0-9._-]{0,63}$=;
   otherwise its slug, =~=, and the first 12 lower-case hex digits of
   FNV-1a 64 (offset basis =0xcbf29ce484222325=, prime =0x100000001b3=)
   over its exact bytes (over a path instead for the =_local= and =_nogit=
   names, =_detached-= and =_wt-=: always hashed, even when plain).
   The slug is the name ASCII-lowercased, every byte outside
   =[a-z0-9._-]= turned into =-=, leading =.= and =-= stripped, cut to 48
   bytes (36 after =_detached-= or =_wt-=), and =_= if nothing is left.  A
   plain name never holds =~= and a marker (=_local=, =_nogit=, =_=,
   =_detached-...~...=, =_wt-...~...=) is never a plain name, so two
   different projects or branches never share a directory; every component
   is ASCII, so case-insensitive and normalizing file systems cannot merge
   two either.

|---------------------------------------------------------+----------------------------------------------|
| =~/src/widget=, origin =git@host:acme/widget.git=, on =main= | =acme/widget/main=                  |

*Limit: case.*  Names are taken as the url and the file system spell
them.  On a case-insensitive disk (macOS, Windows), one forge repository
cloned with differently-cased urls (=Acme/Widget= and =acme/widget=), gets two logs: a
split, never a merge.  Two different names never share a log.  To pin one
location, set =GFORTH_INSPECT_LOG_DIR=, or the =.env= line above.  Git's
own worktrees and branch refs have the same limits on such a disk.

*Limit: symlinks.*  The current directory is the physical path, so a
project reached through a symbolic link is named after the link's target
(=_nogit=, =_local= and =_detached-= names), whichever name was typed.

The directory is created (with parents) by =log-on=, which computes it at
that moment.  *The path is fixed at =log-on= until =log-off=*: a branch
switch, a rebase (detached =HEAD=) or a =cd= does not move an open log.
=log-where= prints the open log's path while logging, and otherwise the
path =log-on= would open now.  A consumer finds the log
by running =gforth inspect.fs -e 'log-where bye'= from the project
directory, or by setting =GFORTH_INSPECT_LOG_DIR= for both sides.  The
reference implementation below gives the same directory; copy it as it
is (=log_dir()= reads =os.environb=; the property tests check
=inspect.fs= against this block):

#+name: log-dir-reference
#+begin_src python
"""Where gforth-inspect writes stacks.jsonl, since 0.3.0 (stacks-log.org, "Files").

log_dir(environ, cwd) returns the directory, as bytes, that inspect.fs
would use for the given environment (os.environb by default) and current
directory (os.getcwdb() by default: the physical path, as getcwd gives it;
$PWD is never read).  Paths and file
contents are bytes throughout; nothing here runs git.
"""
import os

SAFE = b"abcdefghijklmnopqrstuvwxyz0123456789._-"
ROOM = 4352          # inspect.fs's path buffers
LIMIT = ROOM - 13    # a log dir, with room for /stacks.jsonl


def fnv1a64(data):
    value = 0xcbf29ce484222325
    for byte in data:
        value = ((value ^ byte) * 0x100000001b3) & 0xFFFFFFFFFFFFFFFF
    return value


def slug(name, room):
    lowered = bytes(byte | 0x20 if 65 <= byte <= 90 else byte for byte in name)
    mapped = bytes(byte if byte in SAFE else ord("-") for byte in lowered)
    return mapped.lstrip(b".-")[:room] or b"_"


def hashed(prefix, name, room, key=None):
    """prefix, the slug of name, "~", 12 hex of FNV-1a 64 of key (name by default)."""
    key = name if key is None else key
    return prefix + slug(name, room) + b"~" + (b"%016x" % fnv1a64(key))[:12]


def enc(name):
    """One path component: name itself if it is plain, else slug~hash."""
    plain = (1 <= len(name) <= 64 and name[0] in SAFE[:36]
             and all(byte in SAFE for byte in name))
    return name if plain else hashed(b"", name, 48)


def trim(text):
    start, end = 0, len(text)
    while start < end and text[start] <= 32:
        start += 1
    while end > start and text[end - 1] <= 32:
        end -= 1
    return text[start:end]


def read(path):
    try:
        with open(path, "rb") as handle:
            return handle.read()
    except OSError:
        return b""


def basename(path):
    return path[path.rfind(b"/") + 1:]


def find_root(cwd):
    """(root, True) for the nearest ancestor of cwd holding .git, else (cwd, False)."""
    path = cwd
    while True:
        if os.path.exists(path + b"/.git"):
            return path or b"/", True
        cut = path.rfind(b"/")
        if cut < 0:
            return cwd, False
        path = path[:cut]


def unquote(text, quotes):
    if len(text) >= 2 and text[0] in quotes and text[-1] == text[0]:
        return text[1:-1]
    return text


WS = b" \t"


def env_line(line):
    """What follows "=" on a [export] GFORTH_INSPECT_LOG_DIR = ... line, or None."""
    line = (line[:-1] if line.endswith(b"\r") else line).lstrip(WS)
    if line.startswith(b"export") and len(line) >= 7 and line[6] in WS:
        line = line[6:].lstrip(WS)
    if not line.startswith(b"GFORTH_INSPECT_LOG_DIR"):
        return None
    rest = line[len(b"GFORTH_INSPECT_LOG_DIR"):].lstrip(WS)
    return rest[1:] if rest.startswith(b"=") else None


def env_value(raw):
    """Inside a leading ' or " pair; else up to a # after a blank, trimmed."""
    text = raw.lstrip(WS)
    if len(text) >= 2 and text[0] in b"\"'":
        end = text.find(text[:1], 1)
        if end >= 0:
            return text[1:end]
    for index in range(1, len(raw)):
        if raw[index] == ord("#") and raw[index - 1] in WS:
            raw = raw[:index]
            break
    return raw.strip(WS)


def trusted(value, home):
    """A .env is committed and cloned: no ".." segment, and absolute only under $HOME."""
    if b".." in value.split(b"/"):
        return False
    if value.startswith(b"/"):
        if not home:
            return False
        top = home.rstrip(b"/")
        return value == top or value.startswith(top + b"/")
    return True


def dotenv(root, home):
    """<root>/.env's value as a path: ~ and ~/ from $HOME, relative to root;
    b"" when there is none, it is refused (outside $HOME) or too long (both
    with one line on stderr)."""
    raw = b""
    for line in read(root + b"/.env").split(b"\n"):
        found = env_line(line)
        if found is not None:
            raw = found
    value = env_value(raw)
    if not value or not trusted(value, home):
        return b""
    if value == b"~":
        path = home
    elif value.startswith(b"~/"):
        path = home + value[1:]
    else:
        path = value if value.startswith(b"/") else root + b"/" + value
    return path if len(path) <= LIMIT else b""


def git_dir(root):
    dot_git = root + b"/.git"
    if os.path.isdir(dot_git):
        return dot_git
    line = trim(read(dot_git))
    path = trim(line[len(b"gitdir:"):]) if line.startswith(b"gitdir:") else b".git"
    return path if path.startswith(b"/") else root + b"/" + path


def common_dir(gitdir):
    common = trim(read(gitdir + b"/commondir"))
    if not common:
        return gitdir
    return common if common.startswith(b"/") else gitdir + b"/" + common


def normalize(path):
    """path with "", "." and ".." segments resolved lexically ("" for /)."""
    parts = []
    for part in path.split(b"/"):
        if part == b"..":
            parts = parts[:-1]
        elif part not in (b"", b"."):
            parts.append(part)
    return b"".join(b"/" + part for part in parts)


def main_name(common):
    """Basename of the common dir's parent, with . and .. resolved lexically."""
    parts = normalize(common).split(b"/")[1:]
    return parts[-2] if len(parts) >= 2 else b""


def reftable(config):
    """[extensions] refStorage = reftable, line by line as origin_url reads."""
    in_extensions = False
    for line in config.split(b"\n"):
        line = trim(line)
        if line.startswith(b"["):
            in_extensions = line.lower() == b"[extensions]"
        elif in_extensions and b"=" in line:
            key, value = line.split(b"=", 1)
            if trim(key).lower() == b"refstorage" and unquote(trim(value), b'"').lower() == b"reftable":
                return True
    return False


def origin_url(config):
    """The first url of [remote "origin"]: a line-based subset of git-config."""
    in_origin = False
    for line in config.split(b"\n"):
        line = trim(line)
        if line.startswith(b"["):
            in_origin = len(line) == 17 and line[:8].lower() == b"[remote " \
                and line[8:] == b'"origin"]'
        elif in_origin and b"=" in line:
            key, value = line.split(b"=", 1)
            if trim(key).lower() == b"url":
                return unquote(trim(value), b'"')
    return None


def owner_repo(url):
    """(owner or None, repo): repo the last path segment, owner all before it."""
    scheme = url.find(b"://")
    if scheme >= 0:
        rest = url[scheme + 3:]
        path = rest[rest.find(b"/") + 1:] if b"/" in rest else b""
    else:
        colon, slash = url.find(b":"), url.find(b"/")
        path = url[colon + 1:] if colon >= 0 and (slash < 0 or colon < slash) else url
    segments = [segment for segment in path.split(b"/") if segment]
    if not segments:
        return None
    repo = segments[-1][:-4] if segments[-1].endswith(b".git") else segments[-1]
    return b"/".join(segments[:-1]) or None, repo


def branch(head):
    line = trim(head)
    prefix = b"ref: refs/heads/"
    return line[len(prefix):] if line.startswith(prefix) and len(line) > len(prefix) else None


def components(root, has_git):
    """[owner, repo, worktree], each already one safe path component."""
    if not has_git:
        return [b"_nogit", hashed(b"", basename(root), 48, key=root), b"_"]
    gitdir = git_dir(root)
    common = common_dir(gitdir)
    config = read(common + b"/config")
    url = origin_url(config)
    pair = owner_repo(url) if url is not None else None
    if pair:
        owner, repo = pair
        parts = [b"_" if owner is None else enc(owner), enc(repo)]
    else:
        parts = [b"_local", hashed(b"", main_name(common), 48, key=normalize(common))]
    name = None if reftable(config) else branch(read(gitdir + b"/HEAD"))
    if reftable(config) or name == b".invalid":  # reftable: HEAD is a stub
        parts.append(hashed(b"_wt-", basename(root), 36, key=root))
    elif name is None:  # detached: per worktree, by its physical path
        parts.append(hashed(b"_detached-", basename(root), 36, key=root))
    else:
        parts.append(enc(name))
    return parts


def log_dir(environ=os.environb, cwd=None):
    explicit = environ.get(b"GFORTH_INSPECT_LOG_DIR", b"")
    if explicit:
        return explicit
    state = environ.get(b"XDG_STATE_HOME") or environ.get(b"HOME", b"") + b"/.local/state"
    base = state + b"/gforth-inspect"
    cwd = os.getcwdb() if cwd is None else cwd
    if not cwd or len(cwd) + 64 > ROOM:
        return base
    root, has_git = find_root(cwd)
    override = dotenv(root, environ.get(b"HOME", b""))
    if override:
        return override
    derived = b"/".join([base] + components(root, has_git))
    return derived if len(derived) <= LIMIT else base
#+end_src

Append-only. One complete object per line, UTF-8, terminated by a newline;
a consumer that wants "now" reads the last line.

*One producer per log directory is the supported setup.*  The per-worktree
default gives each checkout its own.
Several producers on one log are best-effort. The producer builds each
record in memory and writes it as one whole line at the current end of
the file, so producers that take turns (a REPL and a one-shot
=gforth -e=) never lose a record. Producers writing at the same instant
make an interleaved or lost line rare, but not impossible: gforth 0.7.3
cannot open a file in append mode, so the seek to the end and the write
are separate calls, and a record longer than the stdio buffer can reach
the file in more than one write.

* Data flow

One producer, a file as the interface, independent read-only consumers.
No debugger in the path.

* Records

Every record: ="v": 1=, ="event"=, ="t"= (Unix seconds, integer).

** =hello= (sentinel)

Written once by =log-on=. Tells the consumer a v1 producer is attached and
which contract it speaks.  =inspect= (the producer's =inspect-version=,
since 0.1.0) and =contract= (=MAJOR.MINOR=, since 1.1) are optional in the
schema, so older producers still validate; the consumer rule below decides
whether a consumer reads the stream.

#+begin_src json
{"v":1,"event":"hello","t":1763740800,"gforth":"0.7.3","inspect":"0.4.0","contract":"1.2"}
#+end_src

*Consumer rule (since 1.1).*  A consumer built for contract =M.N= reads a stream
only if its newest =hello= announces exactly =M.N=.  It refuses a stream
with no =hello=, whose newest =hello= has no =contract=, or announces
another MAJOR or another MINOR.  A stream may hold several =hello= records
(one per =log-on=); only the newest counts.  Reference checker:
=test/consumer.py=; streams it must accept and refuse:
=test/contract/streams/=.

** =snapshot=

Written by =.stacks=, =~~~=, and plain =~~= after =all-~~=.

 "where":"fact~","src":"x.fs:3",
 "data":[3,2,1],

| key     | type                    | meaning                                                   |
|---------+-------------------------+-----------------------------------------------------------|
| =id=    | string, optional        | the tag set by =log-id= (since 1.1); absent when none     |
| =where= | string or null          | the word containing the =~~~= or (after =all-~~=) =~~=; null for =.stacks= and for =~~= at the prompt |
| =src=   | string or null          | =file:line= of that =~~~= / =~~=; null when =where= is    |
| =data=  | array of integers       | data stack, bottom first, decimal whatever =BASE= is      |
| =float= | array of numbers / strings / null | float stack, bottom first, 17 significant digits correctly rounded (ties to even), so each parses back to the same binary64 and is the same text on every platform (since 0.4.1, #62), =-0.0= keeps its sign; NaN, +inf and -inf are the strings ="NaN"=, ="Infinity"= and ="-Infinity"= (since 1.2, #66), any NaN is ="NaN"= whatever its sign or payload; =null= is what inspect < 0.4.0 wrote for all three, and still validates |
| =rs=    | array                   | return stack, top first; ={"word","off"}= for a return into a colon definition, ="sp"= for a stack pointer, an integer otherwise; stops at the text interpreter unless =rs-full on= |
| =input= | object                  | =file=, =line=, =in= (=>in=), =text= (the source line)    |

Strings are escaped per RFC 8259: =\"= =\\=, =\n= =\t= =\r= =\b= =\f=,
other control characters as =\u00XX=; bytes that are not valid UTF-8
become =�=.  Numbers never use the bare tokens =NaN= or =Infinity=: a
non-finite float is one of the three strings above, the spelling of
protobuf's JSON mapping (https://protobuf.dev/programming-guides/json/),
so the line stays strict JSON.

* Compatibility

A consumer rejects records whose =v= it does not know. Adding keys is
compatible; renaming or retyping one is a new =v=.

*Breaking = version update.*  Anything that would break one of these three
reference consumers, as they are today, is a breaking change for the inspector
(a new =v= and a MAJOR release), whatever the schema technically allows:

- simple CLI tooling: =tail -f stacks.jsonl | jq -c '{e:.event,w:.where,d:.data,f:.float}'=
  (one complete JSON object per line, append-only, stable key names, numbers
  that parse to the same value);
- an Emacs dashboard as it is (renders the last snapshot; a check that reads
  the newest =hello=);
- a mock API server that serves the last record as-is (=GET /stacks=).

So: removing or renaming a key or an event, changing a type, changing what
=null= means, splitting a record over lines, changing the default file
location, or printing numbers that decode to different values are all
version updates.  New optional keys and new event types that these consumers
can ignore are not.

*Before the first stable tag* (v0.5.0 or v1.0.0) the rule above is applied
as a discipline: a break costs a row in the change log below and a MINOR
=x-contract=, not a new =v= (RELEASING.org, "Rulings").  Contract 1.2
(#66) is one: =float= items widened to include three strings, and =null=
no longer means a non-finite value from 0.4.0 on, under =v= 1.  The
MINOR is what protects a consumer: it stops on =hello.contract= 1.2 until it
is bumped on purpose, so it never meets ="Infinity"= unprepared.

* Changing the contract or the tooling

Every change to a record, a file location, the producer words, or a consumer
follows the same path, in one commit:

1. *Issue first*, on this repository: what changes, why, a reproducer or
   example record, and whether it is additive (MINOR) or breaking (new =v=).
2. *Schema*: =contract/stacks-log.schema.json=.  Additive = a new optional
   property and a MINOR bump of =x-contract=; =x-version= stays.  Breaking =
   bump =x-version= and the =v= const, and the consumer must accept old and
   new during the switch.
3. *Prose*: the record table above and a row in the change log below.
4. *Producer*: =env/inspect.fs= (=contract-version= follows =x-contract=;
   =gmake test= checks they agree).
5. *Consumers*: every reader in [[file:CONSUMERS.org][CONSUMERS.org]]
   gets the same change; downstream copies that carry it before a release
   record it as a deviation.

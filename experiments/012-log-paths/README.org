* Hypothesis

The default log directory of 0.3.0 (=contract/stacks-log.org=, "Files")
maps every project to =<base>/<owner>/<repo>/<worktree>= such that each
component is one safe path component (P1), the same name always gives the
same component (P2), different names never share one, also after
case-folding (P3), and =inspect.fs= computes exactly what the Python
reference in =stacks-log.org= computes, on real fixture trees (P4).

* Prediction

P1-P4 hold for every branch name =git check-ref-format --branch= accepts,
for arbitrary owner and repo bytes, and for every accepted url form; each
of nine planted faults turns P4 red, and the faults that break safety or
injectivity also turn P1 or P3 red.

* Gate

1. =pbt/test_012_log_paths.py= green under =gmake -C pbt check= (100
   examples a property; =PROFILE=ci= 1000), on the working tree's
   =inspect.fs= (=gmake verify=).
2. Branch names come from a wide generator (Unicode, =/=, =.=, =@=, ={=,
   control characters, names up to 300 bytes) and are kept only when real
   git accepts them.
3. =gmake -C pbt calibrate=: every =pbt/calibrate/012-*.sh= red.
4. Every gforth run has its own temp dir as =HOME=, =XDG_STATE_HOME= and
   cwd (E-10, #46); the driver only computes paths, nothing is logged.
5. Pin-on-find: each shrunk counterexample becomes an =@example=.

** 2026-11-22 the project is the current directory, never $PWD (P5)

The coordinator reproduced a clobber: gforth started with cwd = linked
worktree b and $PWD inherited from the main worktree logged to
=acme/widget/main/=.  The brief said 0.7.3 has no getcwd; it has
=get-dir= (all three engines, and 1.0.1), which ignores =$PWD=.  The
project is now found from =get-dir='s physical path; =$PWD= is never read.
The reference takes =cwd= instead of =PWD=.  New property P5,
=test_forth_cwd_beats_pwd=: one gforth per fixture, started in it, =$PWD=
naming another fixture or unset; pinned trio of two linked worktrees and
the main checkout, one engine each.  =pytest test_012_log_paths.py=: 11
passed.  New plant:

| fault                                        | script                  | red |
|----------------------------------------------+-------------------------+-----|
| project from =$PWD= instead of =get-dir=       | 012-root-from-pwd.sh    | P5  |

fault (=NO_P4=1=); the goldens =log-dir-cwd-not-pwd= and =log-dir-no-pwd= go

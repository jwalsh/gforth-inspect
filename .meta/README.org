These are portable findings, filed under the house's three-tier convention:
=experiments/= holds local evidence, =.meta/= holds what generalises, and
anything that two repositories agree on is published as research.

The files are written while the work is going on, not after it. This
directory holds only what is different here.

* What this directory is not

It is not =CONTRIBUTING.org=. That file says what to do. These files say
what was found to be true, and why each rule exists.

It is also not a session log. The test of a finding is whether it still
reads correctly once the context here is gone. Everything in this directory
is public, so the privacy rules in =CONTRIBUTING.org= apply to it too.

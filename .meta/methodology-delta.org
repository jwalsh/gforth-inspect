#+TITLE: Oracles
#+STARTUP: showall

The inspector is a reporter. Judge it by a read that bypasses it.

| oracle                                         | exact              | live | use for                          |
|------------------------------------------------+--------------------+------+----------------------------------|
| lldb at Forth-side =brk=                         | yes                | no   | ground truth, few cases          |
| =depth= =pick= =fdepth= =fpick= =rp@=              | yes (data, float)  | yes  | O-1, O-2                         |
| engine differential (gforth, -fast, -itc)      | relative           | yes  | threading-independent output     |
| JSON schema                                    | shape              | yes  | every record                     |
| model =words.json=                              | declared           | n/a  | declared vs measured deltas      |
| =.s= =f.s=                                       | no                 | yes  | nothing                          |

| ID   | WHEN                           | DO                                              | NEVER                                | CHECK                          |
|------+--------------------------------+-------------------------------------------------+--------------------------------------+--------------------------------|
| O-1  | testing non-interference        | diff the program with vs without inspector      | infer it from the report             | stacks bit-identical           |
| O-2  | testing faithfulness            | compare record to =depth=/=pick=, =fdepth=/=fpick=; floats as bits | compare printed floats  | exact match                    |
| O-3  | need a check from outside image | use engine differential or offline lldb         | trust in-image oracles alone         | fault shared with =depth= visible |
| O-4  | declared ≠ measured effect      | report both sides                               | decide which side is wrong           | finding names both             |
| O-5  | gforth-fast step counts differ  | mask                                            | count as a finding                   | mask documented in test        |
| O-6  | any stack value as data         | read the log                                    | parse =.s= or =f.s=                    |                                |

#+TITLE: Oracles
#+STARTUP: showall

The thing under test is a reporter: =inspect.fs= describes state gforth
already holds. Check the report against that state, read by a path that
bypasses the reporter. Two properties, never one oracle:

- *Non-interference.* Inspector words leave every stack bit-identical.
  Oracle: the same program with and without the inspector.
- *Faithfulness.* The report equals the state. Oracle: =depth= + =pick=,
  =fdepth= + =fpick=; floats compared as bits, never as printed text.

* Oracles, strongest first

| oracle                                              | exact?             | live? | use for                                 |
|-----------------------------------------------------+--------------------+-------+-----------------------------------------|
| lldb at a Forth-side =brk= (=call-c= flushes sp/fp/rp/lp) | yes                | no    | ground truth, a few cases               |
| in-image =depth= =pick= =fdepth= =fpick= =rp@=         | yes (data, float)  | yes   | non-interference, faithfulness          |
| engine differential: gforth / -fast / -itc          | relative           | yes   | anything that must not depend on threading |
| JSON schema                                         | shape only         | yes   | every record                            |
| model =words.json= declared effects                  | declared           | n/a   | declared vs measured depth deltas       |
| =.s= / =f.s= text                                     | rounded, truncated | yes   | nothing: a second reporter              |

* Weak spots

- In-image oracles share the image with the inspector. A fault shared by
  =depth= and the inspector is invisible from inside. Only the engine
  differential and offline lldb see from outside.
- A declared effect is documentation. A disagreement with a measured delta
  means gforth or the model is wrong; the property can't say which.
- gforth-fast keeps TOS in a register and fuses superinstructions. Step-count
  differences there are documented behaviour: mask them, don't count them.

#+TITLE: Experiment process
#+STARTUP: showall

* Roles

| role                | owns                                                        | never touches                          |
|---------------------+-------------------------------------------------------------+----------------------------------------|
| coordinators        | =main=, =experiments/README.org=, =.meta/=, docs, merges       | an experiment's code                   |
| experiment agent    | =../gforth-inspect-NNN-slug=, branch =exp/NNN-slug=, its Log | =main=, other experiments, =env/=, =contract/= |
| producer work       | =env/=, =contract/=, =test/=, root =Makefile=                   | =pbt/=                                 |

Experiments test the inspector; they never fix it. Bug in =env/inspect.fs=:
hand the owner a shrunk case and a one-line reproducer. The finding test
stays red until the fix lands. Never weaken it.

* Loop

1. Coordinator commits to =main=, before the first run: a row in
   =experiments/README.org=, and =experiments/NNN-slug/README.org= with
   hypothesis, prediction and gate.
2. Agent works in a worktree cut from =main=; draft PR at once.
3. Every run goes through =gmake -C pbt check=. Log each run: date,
   inspect.fs provenance (printed by =gforth_run.py=), seed, result.
   Log failures too.
4. Commit and push as you go.
5. Gate met, or finding solid: PR to =main=, through REVIEW.md;
   coordinator merges. A refuted hypothesis merges too, as a Log.

Gate and prediction: never edited after the first run. Log: append-only.

* Isolation

- Test a pinned blob, never a moving name. =INSPECT_REF= selects it; the
  root =gmake verify= sets =INSPECT_REF=HEAD=. (Defaults in =pbt/= still name
  =harden=: follow-up, change to =HEAD=.)
- A calibration about an unfixed producer pins its own ref
  (=CALIBRATE_005_REF=, default =0842eda=). Never follow =INSPECT_REF=.
- Each gforth run: own temp dir, own =HOME= and =XDG_STATE_HOME=, relative
  file names. No record may hold a real path.

#+TITLE: Experiment process
#+STARTUP: showall

| role         | owns                                                    | NEVER touches                                  |
|--------------+---------------------------------------------------------+------------------------------------------------|
| coordinator  | =main=, =experiments/README.org=, =.meta/=, docs, merges  | experiment code                                |
| experiment   | =../gforth-inspect-NNN-slug=, =exp/NNN-slug=, its Log    | =main=, other experiments, =env/=, =contract/=     |
| producer     | =env/=, =contract/=, =test/=, root =Makefile=              | =pbt/=                                          |

| ID   | WHEN                        | DO                                                                  | NEVER                               | CHECK                                  |
|------+-----------------------------+---------------------------------------------------------------------+-------------------------------------+----------------------------------------|
| E-1  | new experiment              | coordinator commits row + =NNN-slug/README.org= (hypothesis, prediction, gate) to =main= | run before the commit       | gate commit precedes first Log entry   |
| E-2  | starting work               | worktree from =origin/main=; draft PR                                 | cut from an unmerged branch         | =gh pr list --draft=                    |
| E-3  | each run                    | =gmake -C pbt check=; Log date, blob, seed, result                    | omit failed runs                    | Log line has blob + seed               |
| E-4  | after first run             | append to Log                                                       | edit gate or prediction             | =git log -p= on gate section empty      |
| E-5  | bug in =env/inspect.fs=      | hand owner shrunk case + one-line reproducer; keep test red         | fix the inspector; weaken the test  | test red until fix lands               |
| E-6  | gate met or refuted         | PR via =docs/REVIEW.md=; coordinator merges; refuted merges as Log    | merge own PR                        | PR body has Review section             |
| E-7  | choosing what to test       | pin by SHA/blob; =gmake verify= sets =INSPECT_REF=HEAD=                | test a moving name                  | provenance line names blob             |
| E-8  | calibrating an unfixed bug  | pin its own ref (=CALIBRATE_005_REF=0842eda=)                        | follow =INSPECT_REF=                  | red on pinned ref, green on fix        |
| E-9  | each gforth run             | own temp dir, =HOME=, =XDG_STATE_HOME=; relative file names            | write the real XDG log              | no record holds an absolute path       |

* Records

Every record: ="v": 1=, ="event"=, ="t"= (Unix seconds, integer).

** =hello= (sentinel)

Written once by =log-on=. Tells the consumer a v1 producer is attached.

#+begin_src json
{"v":1,"event":"hello","t":1763740800,"gforth":"0.7.3"}
#+end_src

** =snapshot=

Written by =.stacks=, =~~~=, and plain =~~= after =all-~~=.

#+begin_src json
{"v":1,"event":"snapshot","t":1763740801,
 "where":"fact~","src":"forth/x.fs:3",
 "data":[3,2,1],
 "float":[2.50000000000000E0],
 "rs":[{"word":"fact~","off":96},"sp",0],
 "input":{"file":"forth/x.fs","line":4,"in":8,"text":"3 fact~ ."}}
#+end_src

| key     | type                         | meaning                                                   |
|---------+------------------------------+-----------------------------------------------------------|
| =where= | string or null               | the word containing =~~~= / =~~=; null for =.stacks=      |
| =src=   | string or null               | =file:line= of that =~~~=; null for =.stacks=             |
| =data=  | array of integers            | data stack, bottom first                                  |
| =float= | array of numbers / null      | float stack, bottom first; null for inf or NaN            |
| =rs=    | array                        | return stack, top first; ={"word","off"}= for a return into a colon definition, ="sp"= for a stack pointer, an integer otherwise; stops at the text interpreter unless =rs-full on= |
| =input= | object                       | =file=, =line=, =in= (=>in=), =text= (the source line)    |

* Compatibility

A consumer rejects records whose =v= it does not know. Adding keys is
compatible; renaming or retyping one is a new =v=.
